# APDF beta builds

Download at https://ap-defence-force.com

This public repo only hosts the release files for APDF: Anomalous Phenomena Defence Force. There is no source here. Builds are published automatically from the private game repo on each `v*` tag as `APDF-windows-<tag>.zip` and `APDF-macos-<tag>.zip`.

Found a bug? [Open an issue](https://github.com/hallmichael/apdf-beta/issues) with what you did, what happened, and the version from the title screen.
